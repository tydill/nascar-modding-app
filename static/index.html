Paint Slot Capacity

The number of paint slots you can create is limited by how many livery UIDs are known to work. Eight ship as verified. Paint Select cannot see UIDs at 25600 or above at all, so that is a hard ceiling. Between the verified-good and verified-broken sets there are untested UIDs, and only launching the game can tell you whether one works.
